1.7 Работа с текстом

В этом уроке мы рассмотрим способы работы с текстом.

Блочные теги (например, <div>, <p>, < h1>–< h6>,) создают разрыв строки и занимают всю доступную ширину родительского элемента, начинаясь с новой строки. Строчные теги (например, < span>, < a>, < strong>,) занимают только то пространство, которое необходимо для их содержимого, и не создают разрывов строки. Это различие важно для верстки и стилизации веб-страниц.


Тег <div >, (от англ. "division" — раздел) используется для создания блочных контейнеров, которые помогают группировать элементы и структурировать содержимое веб-страницы. Он не имеет семантического значения сам по себе, но часто применяется для стилизации или организации макета с помощью CSS.


Тег <span> используется для создания строчных элементов, которые могут быть изменены с помощью CSS. Он не имеет семантического значения, но может быть использован для выделения текста или добавления стилей к части текста.


Тег <strong> используется для выделения важного текста. Он может быть использован для выделения текста, который должен быть выделен, например, при поиске или при наведении курсора на него.


Тег <em> используется для выделения текста, который должен быть выделен, например, при поиске или при наведении курсора на него.


Тег <h1>–<h6> используются для создания заголовков, которые могут быть изменены с помощью CSS. Они могут быть использованы для выделения важной информации или разделения содержимого на страницы.


Тег <br> используется для создания разрыва строки. Он не имеет семантического значения, но может быть использован для организации макета или для добавления пустого пространства между элементами.


Тег <p> используется для создания абзацев, которые могут быть изменены с помощью CSS. Он не имеет семантического значения, но может быть использован для структурирования содержимого веб-страницы.


Тег <img> используется для вставки изображений. Он может быть использован для вставки изображений в веб-страницу, например, для создания логотипа или для добавления изображения в текст.


Тег <a> используется для создания ссылок, которые могут быть изменены с помощью CSS. Он может быть использован для создания ссылок на другие веб-страницы или для добавления ссылки в текст.


Тег <ul> используется для создания списков, которые могут быть изменены с помощью CSS.


Тег <li> используется для создания элементов списка, которые могут быть изменены с помощью CSS.


Тег <ol> используется для создания нумерованных списков, которые могут быть изменены с помощью CSS.


Тег <table> используется для создания таблиц, которые могут быть изменены с помощью CSS.


Тег <tr> используется для создания строк в таблице, которые могут быть изменены с помощью CSS.


Тег <td> используется для создания ячеек в таблице, которые могут быть изменены с помощью CSS.


Тег <form> используется для создания форм, которые могут быть изменены с помощью CSS.
