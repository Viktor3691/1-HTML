1.3 Первые HTML теги

В этом уроке вы выучите свои первые HTML теги.

Вёрстка сайта - это процесс написания кода на HTML и CSS. Результатом этого процесса становится веб-страница.
На языке HTML есть много разных тегов. Это слова записанные в треугольных скобках. Ниже вы видите несколько тегов, которые вы изучите в самом начале. Каждый такой тег имеет свое предназначение. Далее мы будем изучать новые теги, которые позволят нам добавлять: картинки, ссылки, списки, таблицы, формы и многое другое на нашу страницу.

1. <html>

  • Для чего нужен: Это корневой тег, который указывает, что документ является HTML-документом.

  • Пример:

    • <html>
    <!-- содержимое документа -->
    </html>

    2. <head>

  • Для чего нужен: Содержит метаинформацию о документе, которая не отображается на странице, но важна для браузера и поисковых систем.

  • Пример:

    • <head>
    <title> Заголовок страницы</title>
    <meta charset="UTF-8">
    <link rel="stylesheet" href="styles.css">
    </head>

    3. <meta>

  • Для чего нужен: Используется для хранения метаданных, таких как кодировка, описание страницы, ключевые слова и другие настройки.

  • Пример:

    • <meta charset="UTF-8">
    <meta name="description" content="Описание страницы">
    <meta name="keywords" content="HTML, CSS, JavaScript">

    4. <title>

  • Для чего нужен: Задает заголовок страницы, который отображается в заголовке вкладки браузера и в результатах поиска.

  • Пример:


    • <title> Моя первая страница</title>

    5. <link>

  • Для чего нужен: Используется для подключения внешних ресурсов, таких как CSS-файлы, иконки и шрифты.
  • Пример:

    • <link rel="stylesheet" href="styles.css">
    <link rel="icon" href="favicon.ico">

    6. <body>

  • Для чего нужен: Содержит основное содержимое страницы, которое отображается в браузере (текст, изображения, ссылки и т.д.).
  • Пример:

    • <body>
    <h1>
    Привет мир!</h1>
    <p> Это моя первая страница</p>
    </body>

    Итог:
    • <html> - корневой элемент документа.
    • <head> - метаинформация о странице.
    • <meta> — дополнительные настройки и данные.
    • <title> — заголовок страницы.
    • <link> — подключение внешних ресурсов.
    • <body> — содержимое, которое видит пользователь.

    Эти теги формируют основу любого HTML-документа.
