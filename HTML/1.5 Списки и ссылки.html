1.5 Списки и ссылки

В этом уроке вы научитесь создавать списки.




В HTML списки создаются с помощью специальных тегов. Существует три основных типа списков:

  1. Маркированный список (неупорядоченный список):
    Используется тег <ul> (unordered list), а каждый элемент списка обозначается тегом <li> (list item).

    Пример:
    <ul>
        <li> Элемент списка 1 </li>
        <li> Элемент списка 2 </li>
        <li> Элемент списка 3 </li>
    </ul>

    • Элемент списка 1
    • Элемент списка 2
    • Элемент списка 3

  2. Нумерованный список (упорядоченный список):
    Используется тег <ol> (ordered list), а каждый элемент списка обозначается тегом <li>

    Пример:
    <ol>
        <li> Элемент списка 1 </li>
        <li> Элемент списка 2 </li>
        <li> Элемент списка 3 </li>
    </ol>

    1. Элемент списка 1
    2. Элемент списка 2
    3. Элемент списка 3

  3. Список определений:
    Используется тег <dl> (definition list). Каждый термин обозначается тегом <dt> (definition term), а его описание — тегом <dd> (definition description).

    Пример:

    <dl>
        <dt> HTML </dt>
        <dd> Язык разметки веб-страниц </dd>
        <dt> CSS </dt>
        <dd> Язык стилей веб-страниц </dd>
    </dl>

    HTML
    Язык разметки веб-страниц
    CSS
    Язык стилей веб-страниц


Дополнительные атрибуты:

  • Для <ol> можно использовать атрибуты:
      •    
    • type="a" — для маркированного списка.
      •    
    • type="1" — для нумерованного списка.
      •    
    • type="A" — для списка определений.
      •    
    • start="n" — для нумерованного списка, где n — начальное значение.
      •    
    • value="n" — для списка определений, где n — начальное значение.

    Пример:


    <ol type="A" start="3">
       <li> Третий элемент </li>
       <li> Четвертый элемент </li>
    </ol>


    1. Третий элемент
    2. Четвертый элемент
  • Для <ul> можно использовать CSS для изменения маркеров (например, кружки, квадраты, изображения).

    • Пример с CSS:



    <ul style="list-style-type: square;">
       <li> Элемент с квадратным маркером</li>
       <li> Еще один элемент</li>
    </ul>


    • Элемент с квадратным маркером
    • Еще один элемент

    Таким образом, списки в HTML позволяют структурировать информацию и делать её более читаемой.
