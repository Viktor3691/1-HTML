1.9 Атрибуты тегов


Атрибуты в HTML — это дополнительные свойства, которые добавляются к тегам для изменения их поведения, внешнего вида или предоставления дополнительной информации. Атрибуты всегда указываются в открывающем теге и обычно имеют вид имя="значение".


Например:


<a href="https://example.com" target="_blank">Ссылка</a>

Здесь href и target — это атрибуты тега <a>.


Универсальные атрибуты:

Универсальные атрибуты — это атрибуты, которые могут быть использованы с любым HTML-элементом. Некоторые из них:


  • class — задает один или несколько классов для элемента (используется для стилизации на CSS или выбора через JavaScript).
  • id — уникальный идентификатор элемента.
  • style — позволяет задавать CSS-стили напрямую в HTML.
  • title — добавляет всплывающую подсказку при наведении на элемент.
  • hidden — скрывает элемент на странице.
  • data-* — пользовательские атрибуты для хранения дополнительной информации (например, data-id="123").

Пример использования универсальных атрибутов:


<div id="main" class="container" title="Основной блок" hidden>
Это скрытый блок.
</div>
Это скрытый блок.
<div hidden>Этот текст скрыт</&div>
Этот текст скрыт

Атрибут hidden в HTML используется для скрытия элемента на веб-странице. Элемент с этим атрибутом не отображается, но остается в DOM.


DOM (Document Object Model) — это программный интерфейс для работы с HTML и XML документами. DOM представляет документ в виде дерева объектов, где каждый узел (node) соответствует элементу, атрибуту или тексту в HTML.
С помощью DOM JavaScript может:

  • Изменять структуру HTML (добавлять, удалять или изменять элементы).
  • Менять содержимое элементов (текст, атрибуты, стили).
  • Реагировать на действия пользователя (например, клики или наведение мыши).

Подробнее про DOM вы узнаете в разделе по JavaScript, далее в этом курсе.

Атрибут id в HTML используется для уникальной идентификации элемента на странице. Значение id должно соответствовать следующим правилам:

  1. Оно должно начинаться с буквы (A-Z или a-z)..
  2. Может содержать буквы, цифры и символы подчеркивания.
  3. Оно должно быть уникальным в пределах документа.

Атрибут class в HTML используется для назначения одного или нескольких классов элементу. Классы позволяют применять стили или выбирать элементы через JavaScript. Правила для значений атрибута class:

  1. Значение может состоять из нескольких классов, разделенных пробелами.
  2. Классы должны начинаться с буквы (A-Z или a-z) или символа подчеркивания (_).
  3. Классы могут содержать буквы, цифры, дефисы (-), подчеркивания (_) и точки (.).

Атрибут title в HTML используется для добавления всплывающей подсказки (тултипа) к элементу. Подсказка появляется, когда пользователь наводит курсор на элемент. Атрибут title может быть использован практически с любым HTML-элементом, и его значение может быть любым текстом.

<a href="#" title="Перейти на главную страницу">Главная </a>
<img src="../IMG/Viktor1963.jpg" title="Описание изображения" />
<p title="Этот текст имеет подсказку">Наведите на меня</p>
<div title="Информация о блоке">Этот блок имеет подсказку</div>
